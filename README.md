# TSC 4급 13주

중국어 TSC 4급 준비용 개인 학습 앱 (PWA). GitHub Pages로 배포해서 휴대폰 홈 화면에 설치해 쓴다.

## 배포
1. GitHub에서 새 저장소 만들기 (Public)
2. 이 폴더의 파일 전부를 저장소 맨 위(루트)에 업로드
3. Settings → Pages → Branch: main / (root) → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 접속
5. 크롬·삼성 인터넷 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'

## 참고
- 진행 체크, 틀린 단어, 설정은 이 폰 브라우저에만 저장된다.
- AI 문법 분석·AI 한자 설명은 Claude 안에서만 동작해서 이 버전에서는 버튼이 안 보인다.
